Analisa Detak Jantung

Deskripsi
Program ini dibuat untuk menganalisis data detak jantung (BPM) menggunakan bahasa pemrograman Python. Program akan membaca beberapa data detak jantung, kemudian menentukan apakah kondisi tersebut **normal** atau termasuk **takikardia (detak jantung tinggi)**.

Hasil analisis kemudian ditampilkan ke layar dan juga direpresentasikan dalam **format JSON** agar data lebih terstruktur dan mudah digunakan dalam sistem lain.

Fitur Program
- Menyimpan data detak jantung dalam bentuk **list**
- Menggunakan **function** untuk menganalisis kondisi detak jantung
- Menggunakan **perulangan (for loop)** untuk memproses setiap data
- Menampilkan hasil analisis setiap data BPM
- Mengubah hasil output ke dalam **format JSON**

Teknologi yang Digunakan
- Python
- JSON
